功能

📱 手机扫码添加订阅

电视亮出二维码，手机扫码打开网页，填上订阅名称和 M3U 地址一键提交。局域网内直连，数据不出家门。

📋 多订阅管理

MENU 菜单里切换、删除订阅，当前订阅一目了然；订阅名可手填，也能从订阅源内容自动识别。

🔄 应用内自更新

MENU →「检查更新」手动触发，不后台轮询。有新版弹卡片，确认后自动下载并交给系统安装器。

🎮 为遥控器而生

D-pad 上下静默切台、左键召唤频道列表、数字键直接跳台、长按 OK 收藏——全程不碰鼠标键盘。

🛡 播放可靠性

自动重连退避（1s/2s/4s）、15 秒无进度看门狗、连续失败自动跳台；订阅刷新原地合并，不丢收藏和历史。

🪶 轻量纯净

约 4.4 MB 的单一 APK，Media3/ExoPlayer 内核（Apache-2.0），无广告、无追踪、不需要任何权限之外的网络访问。

三步开始

  1. 安装：下载 APK，用 U 盘或 adb install 装到电视。
  2. 添加订阅：首次打开自动进入添加页——手机扫电视上的二维码，填订阅名称和 M3U 地址。
  3. 看电视：提交后自动刷新频道并开始播放；以后打开 app 就是直接看电视。

需要你自己已有 IPTV 订阅地址（M3U 格式）。TVLive 是播放器，不提供任何频道内容。

常见问题

订阅地址从哪里来？

TVLive 播放标准的 M3U / M3U8 播放列表。你需要有自己的 IPTV 订阅地址（运营商、自建或第三方提供），app 负责播放，不内置、不推荐任何内容源。

扫码添加会泄露我的订阅吗？

不会。二维码指向电视在局域网内的临时网页（一次性 token、5 分钟过期），提交直连电视，数据不经过任何第三方服务器。

为什么检查更新失败？

更新清单托管在 GitHub Releases，国内网络访问时通时断。检查失败只提示「已是最新」，随时可以手动到 Releases 页下载。

能装在非电视的 Android 设备上吗？

可以安装，但界面按 TV 遥控器设计（leanback），触屏设备体验不作保证。
